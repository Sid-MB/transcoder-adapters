## 1. Base-vs-adapter circuit-tracing comparison overlay (the headline deliverable)

A patched circuit-tracer frontend that, for each full-replacement attribution graph, tags every node as a **base GemmaScope feature** (hexagon ⬢), an **adapter feature** (circle ●), or a **reconstruction-error node** (triangle ▲, ranked by |influence|), and shows a per-graph banner (`Base ⬢ N · Adapter ● N · Error ▲ N`). Clicking a feature node shows **per-feature proportions** ("fires on X% of tokens" = activation_frequency; top tokens with "NN%" = token_specificity) and **activation examples collected on our chat+web data**. Full replacement `MLP(x) = T_base(x) + T_adapter(x) + Err` yields the real error nodes for free (no RelP).

A complete, ready-to-serve demo (≈477 MB: error triangles + proportions + base AND adapter examples) lives at `/juice2/scr2/siddharth/sparse-adaptation/comparison_demo` (`graph/`, `base_features/`, `adapter_features/`). Serve it, then open http://localhost:8044 :

`uv run --extra viz python -m analysis.attribution.serve_comparison_graphs --graph_file_dir /juice2/scr2/siddharth/sparse-adaptation/comparison_demo/graph --base_features_dir /juice2/scr2/siddharth/sparse-adaptation/comparison_demo/base_features --adapter_features_dir /juice2/scr2/siddharth/sparse-adaptation/comparison_demo/adapter_features --port 8044`

Recipes / entry points: [`sh/visualize_new.sh`](../sh/visualize_new.sh) (`serve_demo`, `quick_smoke`, `demo_local`), [`analysis/attribution/serve_comparison_graphs.py`](../analysis/attribution/serve_comparison_graphs.py), [`analysis/attribution/run_combined_attribution.py`](../analysis/attribution/run_combined_attribution.py). ## 2. Agree-vs-diverge experiment (does circuit tracing work, and does the adapter behave as theorized)

10 prompts where base+instruct **agree** (base does the work) and 10 where they **diverge** (instruct-specific work), each traced into a combined full-replacement graph; node composition aggregated per bucket. Headline result: tracing works (20/20 graphs), the agree/diverge labels are independently validated by KL(instruct‖base), and the adapter recruits more features + leaves more error on diverge — while on agree it is ~100% chat-template "format floor".

Results table — [`experiments/base_vs_adapter_circuit_trace/aggregate_results.json`](../experiments/base_vs_adapter_circuit_trace/aggregate_results.json):

| metric | agree (n=10) | diverge (n=10) |
|---|---|---|
| base features | 253.6 | 251.3 |
| adapter features | 5.9 | 8.9 |
| adapter on template tokens | 5.9 | 8.3 |
| adapter on content tokens | 0.0 | 0.6 |
| error nodes | 63.8 | 102.0 |
| adapter fraction | 0.023 | 0.034 |
| KL(instruct‖base) | 1.11 | 10.30 |

Figure (2×3) — [`.claude/products/base_vs_adapter_circuit_trace.png`](../.claude/products/base_vs_adapter_circuit_trace.png). Regenerate it:
